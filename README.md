A production-ready MCP server that turns fragmented biomedical databases into a unified, agent-callable research layer. Exposes tools across four data sources — PubMed literature search, ClinicalTrials.gov trial discovery, openFDA drug safety and labeling, and ChEMBL compound/target data — so any MCP-compatible client (Claude Desktop, Cursor, or a LangGraph multi-agent system) can perform evidence-grounded landscape research, competitive-intelligence analysis, and innovation forecasting without touching raw API calls.
